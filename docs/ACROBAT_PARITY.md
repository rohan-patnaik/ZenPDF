# ZenPDF Desktop capability matrix

The authoritative 76-row local capability contract is [LOCAL_ACROBAT_PARITY_PLAN.md](LOCAL_ACROBAT_PARITY_PLAN.md).

M0-M6 are historical delivery owners, not compatibility or completion claims. The matrix deliberately keeps work `Partial` or `Blocked` until its required tests and interoperability evidence exist.

The web storage-reservation and orphan-sweep work is operational backend hardening, not a local desktop capability. It therefore changes no row or status in the 76-row desktop matrix.
